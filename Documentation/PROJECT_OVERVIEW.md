# SCS391 Mobile Application Development Lab — Project Overview

## 1. Course & Curriculum Context
- **Course Title:** Mobile Application Development Lab
- **Course Code:** SCS391
- **Academic Standard:** University Degree Practical Lab File
- **Curriculum Scope:** 10 core practical exercises exploring foundational Android development in Java.

## 2. Architectural Principles
1. **Language Fidelity:** Exclusively programmed in Java to satisfy academic syllabus requirements.
2. **Native Android Views & Material Components:** Traditional XML layouts with ConstraintLayout, LinearLayout, ScrollView, and Material Design 3 theme tokens.
3. **Hardware-First QA:** Every runnable application is assembled via Gradle, installed onto a physical OnePlus CPH2661 smartphone running Android 16, and visually documented via native ADB screenshots.
4. **Isolated Project Spaces:** Each practical resides in its own self-contained directory containing complete Gradle build logic, wrapper, manifests, resources, and Java sources.
5. **Unified Academic Record:** A single master Google Document (`SCS391 – Mobile App Development Practical File`) synchronizes aims, theoretical background, step-by-step algorithms, source code listings, hardware screenshots, and conclusion notes across all 10 experiments.
